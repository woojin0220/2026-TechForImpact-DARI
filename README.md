# DARI MVP Android

난민인정신청서 문항에 모국어로 답한 뒤 영어·한국어 번역본을 확인하고, 전체 작성이 끝난 후 번역 왜곡 여부를 검증하는 Android 네이티브 프로토타입입니다.

## Mac 로컬 LLM 검증 테스트

에뮬레이터는 `10.0.2.2:8765`를 통해 이 Mac에만 연결합니다. `local_verification_server.py`는 `127.0.0.1`에만 열리므로 LAN이나 인터넷에 공개되지 않습니다.

```bash
brew services start ollama
ollama pull qwen3:4b
ollama pull llama3.2:3b
python3 local_verification_server.py
```

앱에서 **Qwen3 4B** 또는 **Llama 3.2 3B**를 고르면 선택한 모델이 Mac의 Ollama에서 실행됩니다. 두 모델은 16GB Mac에서 테스트 가능한 양자화 모델이며, Qwen3 14B/32B와 Llama 3.3 70B는 이 장비에서 직접 실행하지 않습니다.

## 포함한 흐름

1. 기기 내 번역 모델 다운로드 동의
2. 선택한 모국어로 전체 문항 답변
3. ML Kit 온디바이스 모국어 → 영어 → 한국어 번역
4. 영어·한국어 병기 최종본 확인
5. 개인정보 제외본을 Mac 로컬 LLM으로 일괄 검증
6. 누락·추가·부정 반전·확실성·행위자·시간·인과·피해 강도 등의 왜곡을 방향과 심각도별로 표시

## 개인정보 원칙

- 입력한 진술은 앱의 메모리에만 유지합니다.
- 번역 요청 문장은 외부 번역 API로 전송하지 않습니다.
- 최초 모델 다운로드에는 Wi-Fi 연결이 필요하며, 이후 번역은 기기에서 실행됩니다.
- 이 프로토타입은 법률 자문이나 난민 인정 가능성 판단을 제공하지 않습니다.

## 실행

Android Studio에서 `DARI-MVP` 폴더를 열고 Android 기기 또는 API 23 이상 에뮬레이터에서 실행합니다. 첫 실행 시 러시아어·영어 번역 모델을 Wi-Fi로 내려받아야 합니다.

## 확인해야 할 사항

- 실제 공식 문항의 러시아어 번역은 공익법센터 어필 또는 공인 통역 검토 후 교체합니다.
- LLM 검증은 번역 왜곡 후보를 찾는 보조 기능입니다. 인물·행위자·부정·불확실성의 의미 보존은 사용자가 재확인하고 필요 시 전문가가 검토해야 합니다.
- 개인정보 마스킹 기준은 추후 확정합니다. 사건 날짜는 검증에 필요하므로 유지하는 것을 기본으로 검토하고, 생년월일·식별번호·이름·주소의 자동 탐지 범위와 국가별 형식은 지원 대상이 정해진 뒤 설계합니다.
