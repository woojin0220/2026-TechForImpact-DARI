    현재 시안과 MAP의 차이

    DARI는 난민신청자가 받은 안내와 실제 진행한 일을 확인하고, 전체 절차 속 현재 위치에서 필요한 준비사항·서류·기관 정보를 찾아가도록 돕는 절차 안내 시안입니다.

    비교 항목MAP 공개 화면에서 확인한 기능현재 DARI 시안의 구현
    정보의 구성체류·건강·돈과 집·일·권리·한국 생활의 6개 정착 주제와 신청 후 시기별 안내신청 준비 → 접수·대기 → 면접 → 결과 대기 → 결정 확인의 신청 절차에 집중
    진행 확인의 기준글별 완료 체크와 체크한 글의 수를 표시
    안내를 보는 동작주제·시기별 안내 글, 관련 글 링크, AI 질문 응답현재 위치와 살펴보는 단계를 분리. 다른 단계를 눌러도 확인한 위치가 바뀌지 않음
    준비 상태서류와 기관 등에 관한 설명을 안내 글과 챗봇으로 제공서류별 ‘준비 중·준비됨·가지고 있지 않음·도움 필요’를 선택하고 없는 경우의 대안 안내 표시. 서류 준비 완료를 접수 완료로 처리하지 않음
    결정 이후심사 결과 뒤의 체류·불복 관련 안내와 관련 글 링크결정 확인의 설명 박스 안에서 인정·불인정을 선택해 필요한 확인사항을 읽음. 선택은 안내 탐색이며 결과를 기관에 신고하거나 조회하지 않음
    기록과 AI정착 가이드의 체크 표시는 기기에 저장. 8개 언어와 사이트 자료 기반 AI 챗봇 제공절차도·위치 확인은 모델 호출 없이 작동. 진행 답변·서류 상태·체크 항목을 이 브라우저에 자동 저장하고 새로고침 시 복원. JSON 파일 백업·열기도 지원. 6개 언어로 안내하며 화면 표시를 위한 AI 모델 호출은 없음

    차별점은 정보량·번역·AI·체크 기능의 유무보다, 확인한 진행 사실과 준비 상태를 연결하는 사용자 흐름에 있습니다. MAP에 유사 기능이 전혀 없다고 단정하지 않습니다. 이 비교는 공개 화면과 현재 HTML 코드에서 확인한 범위이며 실제 사용자 테스트 결과가 아닙니다.

    모델 없이 가능한 핵심 기능

    절차도·위치 확인·서류 상태·기관 안내는 규칙과 사용자 입력으로 동작합니다. 저사양 기기에서도 대형 로컬 모델을 먼저 실행할 필요가 없도록 구성할 수 있습니다.

    로컬 AI는 검토된 안내의 이해·번역을 돕는 역할을 후속 검토합니다. 법적 기한·관할·신청 전략을 모델이 추측하게 하지는 않습니다.

    앱에서 열면 신청서 화면으로 이동할 수 있습니다. 정부 시스템 조회나 신청서 자동 제출 기능은 없습니다.

      상황이 달라졌거나 잘못 답했다면 다시 확인할 수 있습니다.

      확인 기록 백업·열기

      내 위치 확인 답변, 서류 상태와 확인한 항목은 이 브라우저에 자동 저장됩니다. 문서 원본과 피해 진술은 포함하지 않습니다. 파일 백업으로 다른 브라우저나 기기에 기록을 옮길 수 있습니다.

      브라우저 저장 기록과 JSON 백업 파일은 암호화되지 않습니다. 브라우저 데이터를 지우거나 파일 위치·실행 환경이 달라지면 기록이 이어지지 않을 수 있습니다. 기록 파일을 열면 현재 화면과 자동 저장 기록을 대체합니다.

      신청서 작성·검토와 연결

      절차도에서 기존 DARI의 사용자 작성·문장 수정 화면으로 이동하고, 검토한 내용과 출력 파일을 준비한 뒤 돌아오는 흐름을 제안합니다.

      이 시안은 문서를 생성하지 않습니다. 아래 버튼은 서류 준비 상태만 바꾸는 연결 예시이며, 내 위치는 바꾸지 않습니다.

      확인 기록을 초기화할까요?

      이 화면과 이 브라우저에 자동 저장된 위치 확인 답변·서류 상태·체크를 모두 지웁니다. 다운로드한 백업 파일은 삭제되지 않습니다.

      예시로 바꿀까요?

      현재 화면과 자동 저장 기록을 ‘면접을 마치고 결과를 기다리는 상황’의 가상 예시로 대체합니다. 필요한 기록은 먼저 파일로 백업하세요.
