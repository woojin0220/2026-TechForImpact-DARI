# DARI 대화형 수집 테스트 시나리오

모든 인물과 사건은 **시험용으로 만든 가상 이야기**입니다. 실제 신청인의 진술이나 실제 국가·단체를 가리키지 않습니다. 각 시나리오는 14번 문항을 채우기 위한 메타데이터가 올바르게 수집되는지 확인하기 위한 것입니다.

## 사용 방법

### 화면에서 직접 시험

1. Ollama에 `gemma4:e4b`를 준비하고 `python3 local_verification_server.py`, `npm run dev -- --port 5188 --strictPort`를 실행합니다.
2. `http://127.0.0.1:5188/`에서 **한국어**를 고르고 "대화 시작하기"를 누릅니다.
3. 정보 수집 화면에서 **"개발용 · 더미 데이터로 자동 채우기"** 를 누르고 "대화하기"로 넘어갑니다. (더미 입국일 2020/01/01 때문에 늦은 신청 주제가 뒤에 다시 열립니다.)
4. 아래 시나리오의 **입력**을 순서대로 붙여 넣습니다. DARI의 후속 질문은 매번 다를 수 있으므로, 질문에 맞는 내용이 **추가 답변 예시**에 있으면 그것으로 답하고 없으면 "그건 잘 모르겠습니다"라고 답합니다.
5. "이야기는 여기까지"를 누른 뒤 **대화 후 질문**의 답을 고릅니다.
6. "수집한 내용 확인하기"와 한국어 초안 화면에서 **확인할 점**을 봅니다.

### 자동 채점

짧은 검사용 시나리오 10개는 `capacitor-web/src/bench/scenarios.ts`에 대화와 기대 결과가 함께 들어 있습니다. 후보 언어 6개(ko, en, fr, ru, ar, fa)가 모두 들어 있으며, 한국어 외 문장은 원어민 검토 전 초안입니다.

```sh
cd capacitor-web
node --experimental-strip-types scripts/run-intake-scenarios.mjs                         # 전체, 한국어
node --experimental-strip-types scripts/run-intake-scenarios.mjs correction --lang all   # 하나를 6개 언어로
```

검사 항목별 통과·실패와 실제 수집값이 출력됩니다. `basic`·`correction`·`unknown-and-refusal`은 한국어 초안까지 작성해 세 가지를 검사합니다: 인과관계를 강화하지 않았는지, 정정 전 값을 다시 쓰지 않았는지, 불확실성을 빠뜨리지 않았는지. 서버가 이전 요청을 처리 중이면 끝날 때까지 기다렸다가 진행합니다. 세션은 `capacitor-web/tmp/scenarios/`에, 호출별 지연·토큰 기록은 `capacitor-web/tmp/bench/`에 저장됩니다. 실행 옵션(Mac LiteRT-LM, 실기기, 반복 횟수)과 지표 정의는 [경량화 벤치마크](BENCHMARK.md)를 참고하세요.

## 시나리오 1. 정치 활동가 — 여러 사건, 정정, 전해 들은 가족 피해

**인물 설정**: 30대 가상 인물. 가상의 나라에서 야당 청년 모임에 참여했습니다. 2023년과 2024년에 두 번 피해를 겪었고, 동생도 조사를 받았다는 말을 어머니에게 들었습니다. 2025년 1월에 출국했습니다.

**입력**

1. > 이것은 시험용 가상 이야기입니다. 저는 정치적 의견 때문에 보호를 신청합니다. 저는 야당 청년 모임에서 집회 안내문을 나눠 주는 일을 했습니다.
2. > 2023년 3월쯤 집회가 끝난 뒤 경찰이 저를 붙잡아 경찰서에 이틀 동안 가두고 모임 사람들 이름을 대라고 했습니다. 그때 뺨을 여러 번 맞았습니다. 아버지가 보증을 서서 풀려났습니다.
3. > 아, 2023년 3월이 아니라 4월이었습니다.
4. > 그리고 2024년 가을에는 사복을 입은 남자 두 명이 집 앞에서 기다리다가 모임을 그만두지 않으면 가족이 다칠 거라고 협박했습니다. 그 사람들이 누구였는지는 정확히 모르지만 경찰이라고 생각합니다.
5. > 제 동생도 2024년 말에 경찰서에 불려가 저에 대해 조사를 받았다고 어머니에게 전화로 들었습니다.
6. > 돌아가면 다시 붙잡혀서 이번에는 오래 갇힐까 두렵습니다. 2025년 1월에 나라를 떠났습니다.

**추가 답변 예시**

- 경찰서 위치를 물으면: "수도에 있는 중앙 경찰서였습니다."
- 다친 곳을 물으면: "얼굴이 붓긴 했지만 병원에는 가지 않았습니다."
- 왜 그랬다고 생각하는지 물으면: "제가 야당 모임에서 활동했기 때문이라고 생각합니다."

**대화 후 질문**: 보호 요청 → 아니요 / 국내 피신 → 아니요 / 단체 가입 → 예 (성명: 본인, 관계: 본인, 기간: 2022~2024, 단체명: 가상 청년연대, 역할: 안내문 배포) / 나머지 → 아니요. 이후 "보호를 요청하지 않은 이유"와 "피신하지 않은 이유"를 묻는 대화가 다시 열리면 각각 "경찰이 저를 괴롭힌 쪽이라 도움을 청할 수 없었습니다", "어디로 가도 신분증 검사로 찾아낼 것 같았습니다"라고 답합니다.

**확인할 점**

- [ ] 본인 피해가 **사건 2개**로 나뉨 (2023년 구금·폭행 / 2024년 협박)
- [ ] 첫 사건 시점이 **4월**로 정정되고 3월 값은 대체됨
- [ ] 두 번째 사건 피해 유형이 **위협**뿐이며 폭행·구금이 섞이지 않음
- [ ] 두 번째 사건 행위자가 "경찰이라고 생각"하는 **추정**으로 남음 (확정 사실로 바뀌지 않음)
- [ ] 동생 사건이 본인 사건과 분리된 **가족 피해**이며, 알게 된 경위가 **전해 들음**
- [ ] 출국일 2025년 1월, 14.7에 계산됨
- [ ] 14.2·14.3·14.4 **예**, 14.5·14.6 **아니요**, 14.8 표에 1행
- [ ] 보호 요청·피신을 하지 않은 이유가 대화로 다시 수집됨
- [ ] 한국어 초안이 "그 뒤"를 "이 일 때문에"처럼 **인과관계로 강화하지 않음**

## 시나리오 2. 종교 신자 — 자녀 동반, 보호 요청, 국내 피신, 증거

**인물 설정**: 40대 가상 인물. 소수 종교 신자이며 8살 딸, 남편과 함께 한국에서 신청했습니다. 경찰에 보호를 요청했지만 거절당했고, 다른 도시로 피신했다가 다시 떠났습니다. 교회 회원증을 가지고 있습니다.

**입력**

1. > 이것은 시험용 가상 이야기입니다. 저는 종교 때문에 신청합니다. 저희 가족은 나라에서 인정하지 않는 작은 교회에 다닙니다.
2. > 2024년 2월쯤 이웃들이 우리 집 창문에 돌을 던지고 문에 협박하는 글을 써 놓았습니다. 그래서 동네 경찰서에 신고했지만 경찰은 우리 종교 문제에는 끼어들지 않겠다며 접수하지 않았습니다.
3. > 그 뒤 2024년 4월에 남편 고향인 다른 도시로 옮겨 살았는데, 그곳 사람들도 우리 교회를 알게 되어 6개월 뒤 다시 떠나야 했습니다. 나라 안에서는 어디를 가도 같은 일이 생길 것 같았습니다.
4. > 이번 신청은 8살 딸과 함께 했습니다. 아이 아빠인 남편도 한국에 같이 있습니다.
5. > 교회 회원증과 창문이 깨진 사진을 가지고 있습니다. 회원증은 교회에서 받았고 사진은 제가 직접 찍었습니다. 다음 면접 때 제출하려고 합니다.

**대화 후 질문**: 귀국 시 우려 → 예 / 가족 피해 → 아니요 / 단체 → 아니요 / 반대 활동 → 아니요 / 범죄 → 아니요 / 다른 나라 신청 → 아니요 / 가족 연락 → 예. "귀국 시 우려"에 대한 대화가 다시 열리면 "돌아가면 이웃들이 또 공격하고 경찰은 보호해 주지 않을 것입니다"라고 답합니다.

**확인할 점**

- [ ] 본인 피해 1건 (돌 던짐·협박), 행위자 **이웃**
- [ ] 보호 요청 **예**, 요청 대상 동네 경찰서, 결과 **접수 거부**
- [ ] 국내 피신 **예**, 시점 2024년 4월, 지역 남편 고향, 떠난 이유와 다른 곳에서도 살 수 없는 이유가 각각 기록
- [ ] 자녀 1명, 나이 8, 관계 **아이의 부모이고 다른 부모도 한국에 있음**
- [ ] 증거 2건(회원증, 사진)이 **항목별로** 기록되고 14.16 표에 2행
- [ ] 신청 사유 범주가 **종교**로만 기록됨

## 시나리오 3. 이유를 모르는 피해와 말하기 어려운 내용

**인물 설정**: 20대 가상 인물. 무장한 사람들에게 마을이 공격받아 피신했지만 공격 이유를 모릅니다. 일부 경험은 지금 말하고 싶어 하지 않습니다.

**입력**

1. > 이것은 시험용 가상 이야기입니다. 무장한 사람들이 우리 마을에 와서 집을 불태웠고 저도 위협을 받아 도망쳤습니다. 왜 우리 마을이 공격받았는지는 잘 모르겠습니다.
2. > 정확히 언제였는지는 기억나지 않습니다. 비가 많이 오던 때였던 것 같습니다.
3. > 도망치는 동안 있었던 일은 지금은 말하고 싶지 않습니다.

**대화 후 질문**: 신청 사유(14.1)에서 **"모르겠어요"** 를 누릅니다. 나머지 예/아니요는 "지금은 답하지 않을게요"를 누릅니다.

**확인할 점**

- [ ] 신청 사유 범주가 **추정으로 채워지지 않음** (모델이 정치·민족 등을 고르지 않음)
- [ ] 피해 이유가 **답변으로 기록되지 않음** (빈 칸 또는 모름)
- [ ] 시점이 **모름**이며 "비가 많이 오던 때"가 대략적 단서로 남음
- [ ] 말하고 싶지 않다고 한 내용이 **답변 보류**로 기록되거나 비어 있음, DARI가 다시 캐묻지 않음
- [ ] 수집 내용 화면의 "앞으로 확인할 내용"에 남은 항목이 표시됨

## 짧은 검사용 시나리오 (자동 채점)

`src/bench/scenarios.ts`의 10개 시나리오입니다. 화면에서도 같은 문장을 붙여 넣어 시험할 수 있습니다.

| ID | 확인하는 것 |
| --- | --- |
| `basic` | 한 사건, 대략적인 날짜, 귀국 시 우려, 14.2 = 예 |
| `two-incidents` | 사건 2개 분리, 첫 사건에 두 번째 사건의 폭행이 섞이지 않음, 이유 모름을 추정하지 않음 |
| `correction` | 3월 → 4월 정정 시 이전 값 대체 |
| `refinement` | 장소를 더 자세히 다시 말할 때 충돌 대신 갱신 |
| `hearsay-family` | 본인 피해 없음 + 형의 피해를 전해 들음, 14.4 = 예 |
| `narrow-denial` | "때리거나 가두진 않았다"가 피해 없음이 되지 않음 |
| `unknown-and-refusal` | 기억나지 않는 날짜는 모름, 말하기 싫은 내용은 기록하지 않음 |
| `no-category` | 이유를 모를 때 신청 사유 범주를 추정하지 않음 |
| `protection-relocation` | 보호 요청을 하지 않은 이유, 국내 피신 1건, 14.5 = 아니요, 14.6 = 예 |
| `children` | 자녀 나이 8, 관계 = 두 부모 모두 한국에 있음 |
