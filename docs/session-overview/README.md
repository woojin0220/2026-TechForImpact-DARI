# 전체 내용 보기

상단의 **전체 내용 보기** 버튼으로 현재 화면 위에서 양식 입력, 수집된 답변, 한국어 초안, 전체 대화와 이전 기록을 스크롤해 확인합니다. 닫으면 원래 화면과 입력이 유지됩니다.

직접 입력한 값과 사용자 대화 원문, 추출된 답변, 사용자가 확인한 답변을 구분합니다. 확인 배지는 실제 `confirmed` 상태를 사용하고 충돌·이전 기록에는 확정 표시를 하지 않습니다. 열람만으로 확인 상태가 바뀌지 않습니다.

문항·주제·사건별로 구분하며 입력 중인 문장, 숨겨진 양식 값, 빈 표·부분 입력 행, 실패한 처리 뒤의 원문도 보존합니다. 문장 수정 대화와 제안·변경 이력은 별도 영역에 표시합니다.

수정 버튼은 기존 양식, 선택형 답변, 정정 입력창 또는 한국어 초안의 해당 항목으로 이동합니다. 표의 빈 행을 고려해 정확한 입력 칸에 포커스를 둡니다. 숨겨진 조건부 입력은 해당 항목을 확인할 수 있도록 설명과 함께 표시합니다. 현재 서식에 없는 저장 항목은 원문을 표시하고 수정 화면 미지원 이유를 안내합니다.

모바일에서는 화면 높이에 맞는 모달 안에서 전체 내용을 스크롤할 수 있으며 닫기 버튼이 유지됩니다. 아랍어·페르시아어 UI는 RTL, 한국어 초안은 LTR로 분리합니다. 한국어·영어·아랍어·프랑스어·러시아어·페르시아어의 새 문구를 제공합니다.

## 검증

- 전체 테스트 163개 통과, 실패 0개. TypeScript와 Vite 빌드 통과.
- 아랍어 UI 키 377개, 고유 라벨 426개를 감사했으며 누락 0개.
- 브라우저에서 실제 App과 명시적 가상 자료 fixture를 사용해 수정 이동·미전송 입력 보존·ESC·포커스·390px 스크롤·RTL을 확인했습니다.
- 새 회귀 검사: 모델 5개, 표 행 탐색 5개, 실제 React 렌더링/문구 8개.
- 물리적 휴대폰 시험과 원어민 감수 결과는 포함하지 않습니다.

## 개발 실행

저장소의 기존 Ollama/API 준비 후 `capacitor-web`에서 `npm ci`, `npm test`, `npm run build`, `npm run dev -- --host 127.0.0.1 --port 5173`을 실행합니다. 기본 모델은 기존 gemma4:e4b입니다.

`tests/ui/session-overview-app.html`은 원문·확인 상태·초안·수정 대화가 있는 가상 자료로 실제 App 이동을 점검하는 개발용 화면입니다. 일반 앱 시작 화면과 프로덕션 빌드에는 포함되지 않습니다. App의 선택적 initialSession/initialStage는 이 검증에만 사용하고 일반 시작 동작은 유지합니다.

## 브랜치 관계

`feat/session-overview`는 `fix/arabic-localization-rtl` 수정본을 기준으로 합니다. 아랍어 수정이 유지되며 기능만 검토하려면 두 브랜치를 비교합니다. 새로고침 복원·자동 저장은 이번 기능에 추가하지 않았습니다.
