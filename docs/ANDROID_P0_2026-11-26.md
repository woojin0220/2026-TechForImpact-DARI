# Android MVP: P0 수정 (2026-11-26)

## 기준 재확인

감사 문서는 feat/community-ux 1eaf240 기준이며 당시 신청서 코드는 main ac92fb8과 같았다. 이번 수정 기준은 feat/form-preview dba9f6a를 상속한 fix/android-application. 추가된 선택적 안내·모국어 작성본/원본 미리보기는 유지했다. 두 P0 경로(공용 일정 키, 출력 중 자동 번역)는 최신 신청서 브랜치에도 남아 있었다. 커뮤니티 검색 개선은 이번 브랜치에 합치지 않았다.

## P0 A — 일정·절차 소유자 범위

- 로그인 계정 ID를 기준으로 일정·달력 뷰·절차·절차 뷰의 저장 키 분리. 게스트와 독립 안내도 별도 namespace.
- 계정 전환 시 절차 컴포넌트와 iframe 재마운트. 메시지 origin/source 검사 유지. 신청서 원문은 iframe에 전달하지 않음.
- 예전 공용 localStorage 기록은 그대로 보존하며 새 계정으로 자동 이전하거나 삭제하지 않음.
- 절차 백업에 소유자 scope를 기록하고 다른 계정 소유 백업의 가져오기 차단. 예전 소유자 정보 없는 백업은 사용자가 파일을 직접 선택한 경우에만 현재 범위에 가져올 수 있음.
- 기존 절차 백업에는 일정 데이터가 포함되지 않는 정책 유지. 일정과 절차 백업을 동일 파일이라고 설명하지 않음.
- namespace는 암호화·동일 기기의 물리 접근 방지·서버 인증 보장을 뜻하지 않음. 기존 공용 기록을 복구할 필요가 있으면 지원 절차를 통해 명시적으로 이전해야 함.

## P0 B — 번역과 사용자 확인 분리

- 다운로드는 번역 모델을 호출하지 않음. 미번역·미확인 문항 목록과 이동 제공.
- 자동 번역의 최신 여부와 사용자의 명시적 확인을 별도 저장. 원문·번역·입력/목표 언어 및 번역 기준 버전에 확인 상태를 귀속.
- 해당 값이 변경되면 확인 해제. 편집 후 원래 문자열로 되돌려도 재확인 필요.
- 예전 답변은 내용·번역을 유지한 미확인 상태로 복원. 명시적으로 확인한 기록은 같은 계정·탭의 새로고침 후 유지.
- 서술형 검토에서 원문을 기본 펼침. 단답형·선택형도 번역·출력할 값을 보고 확인. 확인 전에는 저장 후 복귀 버튼/Word 출력 차단; 원문 자체는 자동 저장됨.
- Word encoder에서도 별도로 확인 상태를 검사하므로 상위 다운로드 UI만 우회해서 미확인 답변을 출력하지 못함.
- 읽기 어려운 번역은 신뢰하는 조력자와 검토하도록 안내. 체크는 법적 동의나 번역 정확성 보증이 아님.
- 확인 상태는 정확한 내용의 snapshot으로 비교하므로 별도 텍스트 사본만큼 저장 공간이 추가됨. sessionStorage 용량 부족은 기존 저장 오류 안내로 처리. 클라우드 저장·장기 보존으로 변경하지 않음.

## 확인한 결과

- 307개 회귀 테스트 통과. 신규 상태·소유자 계약 테스트 포함.
- 웹 빌드 통과.
- 실제 브라우저 UI: 6개 언어, 320/390px, 확인 전 출력 차단, 명시 확인 후 Word 다운로드, 번역/원문 수정 후 확인 해제, 새로고침 복원, 다운로드 시 모델 요청 0건.
- 실제 절차 페이지에서 계정 scope A→B→A→guest→standalone→B를 전환하며 일정·체크 복원 분리, 예전 공용 키 자동 이전 없음, 다른 소유자 백업 거부 확인.
- UI 검증은 가상 Supervisor/테스트 scope와 사전 번역 데이터를 사용. 운영 Supabase에서 서로 다른 실제 계정의 인증을 시험한 결과는 아님. 번역 모델의 실제 품질·latency, APK·실기기 실행은 이번 P0 범위에서 검증하지 않음.
