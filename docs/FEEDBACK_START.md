# DARI 모바일 체험

## 체험할 내용 (약 10~15분)

1. 사용할 언어 선택 → 체험 계정 입장
2. 신청서의 기본 정보 한 문항 작성
3. 14.2 문항에 아래 가상 진술 입력 → 한국어 번역 → 원문과 비교·수정 → 확인
4. 미리보기 → PDF 또는 HWP 선택 → 저장·공유
5. 스케줄러에서 현재 단계·일정 등록, 커뮤니티에서 글 작성 확인

**가상 진술**

> Two men came to my home and threatened me. I think they were police officers, but I am not certain. I do not remember the exact date. It was around the beginning of March. I was not detained. My neighbor later told me they came back, but I did not see that myself.

첫 번역에는 언어 모델 다운로드가 필요합니다. Wi-Fi 연결을 권장합니다. 준비 후 번역은 기기 안에서 실행됩니다. 처음 시험에는 가상 정보만 입력해 주세요.

## 의견을 부탁드리는 부분

| 항목 | 질문 |
|---|---|
| 작성 과정 | 처음 사용하는 사람도 문항을 이해하고 혼자 작성할 수 있나요? |
| 번역 | 불확실한 기억, 부정, 타인에게 들은 내용이 다르게 표현되나요? |
| 결과물 | 미리보기·저장 결과와 인쇄 후 자필 작성·서명 안내가 명확한가요? |
| 활용 범위 | 실제 신청 지원에 사용할 때 우려되는 점이나 반드시 보완할 점은 무엇인가요? |

체험용 계정의 커뮤니티는 샘플 데이터입니다. 실제 다른 사용자에게 게시되지 않습니다. 번역 엔진은 Google ML Kit이며, 법률적 정확성이 보증되는 번역기는 아닙니다.
