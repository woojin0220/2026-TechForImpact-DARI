# 신청서 원본 양식 PDF 출력

## 범위

Issue #9의 PDF 출력 경로. 초안 화면 → 신청서 내보내기 → 전체 답변 검토 → PDF 생성 → 미리보기/다운로드.
PDF 출력은 제공된 HWP에서 만든 PDF를 템플릿으로 사용한다. 편집 가능한 HWP 출력은 [APPLICATION_HWP.md](APPLICATION_HWP.md)를 참고한다.
정부기관 제출, 법률 판단, 미응답 사실의 생성은 하지 않는다.

## 원본과 버전

- `capacitor-web/public/forms/refugee-application-2019.hwp`: 사용자가 제공한 원본 복사본. 개정일 2019.12.31.
- 같은 경로의 PDF: 한컴오피스 한글의 ‘PDF로 저장하기’로 만든 22쪽 복사본. 최종 변환본의 첫 쪽 및 답변 영역, 서약/신청란을 렌더링해 확인했다. 최초 변환 때 첫 쪽이 비어 있어 폐기하고 문서가 완전히 로드된 후 재변환했다.
- 먼저 제공된 2021년 PDF와 앱 스키마 주석의 2024년 표기는 서로 다르다. 이 기능은 2019년 양식으로 고정되며 최신 법정 서식으로 인증하지 않는다.
- 템플릿을 교체할 때 파일만 덮어쓰면 안 된다. 문항, 선택지 위치, 표 열 순서를 모두 재대조하고 `placements.ts`와 버전 안내 및 테스트를 함께 갱신해야 한다.

## 데이터와 배치

- `src/export/plan.ts`: 현재 `session.form`과 `session.question14`의 화면 표시 조건을 적용한다. `draft`의 이전 문장을 출력에 재사용하지 않는다. 미입력은 빈칸, 사용자가 명시한 모름/해당 없음은 별도 상태로 보존한다.
- `src/export/placements.ts`: 원본 PDF를 778×1100으로 렌더링해 측정한 1-based 페이지 번호와 좌표. 모든 비서약 문항/선택지 및 표 열에 매핑 테스트가 있다.
- `src/export/pdf.ts`: pdf-lib + fontkit. 선택은 벡터 체크 기호로 표시하고 표 데이터는 세로 중앙에 배치한다. 한글은 정적 나눔고딕 TrueType을 포함한다. CFF 및 가변 폰트의 서브셋은 뷰어별 깨짐/폭 불일치가 있어 사용하지 않는다. 전체 폰트를 포함해 생성한 가상 결과는 약 1MB다. 폰트 출처는 Google Fonts `ofl/nanumgothic`, 라이선스는 public/fonts/OFL-NanumGothic.txt.
- 짧은 문자열과 표는 원본에 채운다. 문자열이 지정 영역을 넘거나 표의 행/셀 높이가 넘으면 전체 답변을 번호 별지에 보존한다. 별지는 22쪽 원본 뒤에 붙고 계속 페이지에도 문항 번호가 표시된다.
- 미작성/불확실/불완전 표/미해결 차이 등은 마지막의 ‘출력 검토 목록’에서 확인한다. 목록은 신청서의 답변이 아니다. 원본 서약, 서명, 동의, 신청일, 기관 작성란은 비워둔다.
- 편집 후 PDF가 이전 내용을 계속 가리키지 않도록 스냅샷 URL을 폐기하고 재생성하도록 한다. Blob URL은 해제한다.

## 검증

```sh
cd capacitor-web
npm ci
npm run build
npm test
# 가상 데이터 PDF 파일도 생성하려면:
DARI_EXPORT_FIXTURE=/tmp/dari-filled-review.pdf node --experimental-strip-types --test tests/application-export.test.mjs
pdftoppm -f 3 -l 3 -png /tmp/dari-filled-review.pdf /tmp/dari-page
```

테스트: 전체 매핑, 조건부 필드 숨김, 현재 수정문 사용, 세션 불변성, 모름/해당 없음/미작성 구분,
표의 빈 셀 표시, 긴 문자열과 여러 문단, 별지 계속 페이지, 지원 불가능 문자 차단, PDF 재열기.
실제 신청자 데이터가 아닌 가상 데이터로만 검사한다.

## 제한 및 후속 작업

- 현재 수집 흐름에서 제공하지 않는 문항은 출력도 빈칸이다. 15번 추가 진술과 수기 작성 영역을 포함해 제출자가 직접 확인해야 한다. ‘문서가 생성됨’은 ‘신청서 작성 완료’ 또는 ‘법률 검증 완료’를 의미하지 않는다.
- 직접 입력한 인적사항은 원래 표기 그대로 출력한다. 한국어로 새로 번역하거나 이름/날짜를 임의로 보정하지 않는다.
- 나눔고딕이 지원하지 않는 문자(일부 언어/이모지)는 문항 번호를 알려주고 차단한다. 다른 글자로 조용히 대체하지 않는다. 추가 다국어 폰트 및 RTL PDF 조판은 후속 범위다.
- 브라우저 PDF 미리보기를 지원하지 않는 모바일 환경에서는 별도 탭 미리보기/다운로드 링크를 이용한다. 실제 iOS/Android 앱의 파일 저장·공유 권한 및 기기별 동작은 추가 검증해야 한다.
