# 커뮤니티

로그인·가입을 마친 회원이 질문하고 생활 정보를 나누는 게시판입니다. 계정·역할·뱃지 구조는 [PLATFORM_AUTH.md](PLATFORM_AUTH.md)를 따릅니다. 신청서 데이터는 계속 기기에만 남고 커뮤니티 계정과 연결되지 않습니다.

## 게시판

| 게시판 | id | 글쓰기 |
| --- | --- | --- |
| Q&A | `qna` | 모든 회원 |
| 생활정보 | `life` | 모든 회원 |
| 공지사항 | `notice` | 지원기관(supporter)·운영자·관리자만 |

게시판은 `boards` 테이블에 있으므로 SQL 한 줄로 추가할 수 있습니다. 앱의 게시판 이름 문구(`board_<id>`)도 함께 추가해야 합니다.

## 화면 (`capacitor-web/src/community/`)

| 파일 | 역할 |
| --- | --- |
| `CommunityScreens.tsx` | 홈(Q&A·생활정보·공지사항 탭, 처음엔 Q&A, 카드형 글 목록, 더 보기, 글쓰기 버튼. 일반 회원은 공지사항 탭에서 글쓰기 버튼이 보이지 않음), 글보기(도움됐어요, 댓글, 신고·차단·삭제, 하단 고정 댓글 입력), 글쓰기(게시판 칩 선택, 상단 등록 버튼) |
| `api.ts` | Supabase 조회·쓰기. 권한은 모두 서버의 행 수준 보안(RLS)이 판단합니다 |
| `model.ts` | 데이터 형태, 제목·본문 검사, 민감정보 감지, 상대 시간 표시 |
| `copy.ts` | 6개 언어 문구 (ko, en, fr, ru, ar, fa) |

`src/shell/CommunityTab.tsx`가 로그인 확인(AuthGate) 뒤에 목록 → 글보기 → 글쓰기 → 내 정보 화면을 전환합니다.

## 개인정보 보호와 안전장치

- 작성자는 닉네임과 공개를 선택한 뱃지(난민 인정, 지원기관)만 보입니다. 이메일은 다른 회원에게 보이지 않습니다.
- 글·댓글에 전화번호, 이메일, 외국인등록번호·여권번호로 보이는 내용이 있으면 등록 전에 경고합니다. 아랍어·페르시아어 숫자도 감지합니다. 경고 후 다시 누르면 등록됩니다(차단이 아니라 확인).
- 신고 사유: 다른 사람의 신원·사건 노출, 사기·돈 요구, 혐오·괴롭힘, 스팸, 기타. 같은 사람이 같은 글을 두 번 신고할 수 없습니다.
- 서로 다른 회원 3명이 신고하면 운영자 확인 전까지 자동으로 숨겨집니다.
- 회원을 차단하면 그 회원의 글과 댓글이 내 화면에서 사라집니다.
- 내 글·댓글은 삭제할 수 있습니다(`delete_own_content`). 숨김·복구는 운영자만 할 수 있습니다(`moderate_content`, `resolve_report`).
- 탈퇴한 회원의 글은 "탈퇴한 회원"으로 표시됩니다.

## 데이터베이스 (`supabase/migrations/20261119000000_community.sql`)

- 테이블: `boards`, `posts`, `comments`, `post_reactions`(도움됐어요), `reports`, `blocks`
- 뷰: `post_feed`, `comment_feed` (`security_invoker`라 조회하는 회원의 권한이 그대로 적용됨)
- 작성자는 제목·본문만 고칠 수 있고 상태·신고 수·게시판은 바꿀 수 없습니다(트리거로 막음).
- 정지된 회원은 글·댓글·반응·신고를 쓸 수 없습니다.

테스트: `supabase/tests/community_test.sql` (로컬 Postgres에서 `local_auth_stub.sql`과 모든 마이그레이션을 적용한 뒤 실행).
