# 커뮤니티 사용자 피드백용 통합본

## 현재 구성

Q&A·생활정보·공지의 3개 게시판 유지. 검색·글쓰기·저장한 글에 본인 글 수정, 댓글 초안, 내 활동을 추가했다.

| 영역 | 반영 내용 |
| --- | --- |
| 탐색 | 상단 제목·게시판·검색 고정, 글 목록만 스크롤. 구분선과 여백 보강. 검색 입력 내부 포커스 테두리 제거, 검색창 전체에 포커스 표시 |
| 화면 간소화 | 답변 없는 질문 필터·최신 글 표시·상시 소개문 제거 |
| 첫 방문 | 계정·기기별 3단계 안내 오버레이. 건너뛰기·Escape 지원. 상단 ?로 다시 열기 |
| 글 관리 | 본인 글 상세에서 수정. 기존 제목·본문·언어 불러오기, 저장 성공 뒤 상세 복귀. 신규 글 초안과 수정 입력 분리 |
| 댓글 초안 | 계정·게시글별 sessionStorage. 뒤로 가기·탭 이동·새로고침 복구. 전송 실패 시 유지, 성공 시 제거. 저장 실패 표시 |
| 내 활동 | 상단 말풍선 아이콘 → 내 글 / 내 답변. 서버의 본인 활동 조회, 삭제·숨김·차단 글 제외, 추가 불러오기 |
| 자동 번역 | 선택한 앱 언어로 목록 제목·미리보기·상세·댓글 자동 번역. 원문 유지 및 상세/댓글 원문 전환. 기기 번역기 미연결·처리 중·실패 구분 |

신청서·일정·박해 진술은 커뮤니티에 자동 공개하지 않는다. 개인정보 주의는 글 작성 화면에 유지한다.

## 저장·권한 경계

게시글/댓글 초안은 현재 브라우저 탭에 저장하며 탭 종료 후 보존은 보장하지 않는다. 저장한 글은 계정별 localStorage에 ID만 최대 200개 저장한다. 본인 활동은 기존 Supabase에서 조회한다. 수정은 본인·공개 상태 조건과 기존 RLS를 함께 사용하며 새 DB migration은 필요하지 않다. Supervisor는 별도 로컬 가상 데이터만 변경한다.

## 번역 환경

Android ML Kit가 있으면 오프라인 번역을 사용한다(처음에는 언어 모델 다운로드 필요). 그 외에는 준비된 기기 모델·로컬 미리보기 모델을 사용한다. 느린 모델도 화면에 보이는 목록부터 자동 번역하며 동시 실행은 1개, 빠른 번역기는 2개로 제한한다. 번역 캐시와 중복 요청 결합을 적용한다. Hybrid 외부 모델로 자동 우회하지 않는다. Supervisor도 실제 번역기가 준비되면 같은 경로를 사용한다.

번역기 미연결 시 원문과 상태를 표시한다. 원문 검색이며 번역문 전체를 대상으로 한 서버 검색은 이번 범위가 아니다.

## 확인 결과와 남은 검증

319개 테스트·웹 빌드 통과. 6개 언어, 320/390px에서 첫 방문 안내, 본인 글 수정, 댓글 이동/새로고침 복구와 전송 후 정리, 내 글·답변, 상단 고정과 입력 포커스를 확인했다. 데이터는 Supervisor 가상 데이터다. 자동 번역·원문 전환은 명시적인 가짜 로컬 모델 응답으로 연결 동작을 확인했으며 번역 품질 시험은 아니다.

실계정 Supabase 2개 계정의 RLS, 실제 Android 번역 엔진/다운로드/속도, 동일 시각 게시물의 기존 timestamp 페이지 경계, 서버 전송 재시도의 멱등성은 별도 검증 대상이다. 이번에 운영 DB나 APK를 검증했다고 주장하지 않는다.
