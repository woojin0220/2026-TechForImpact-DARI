# 커뮤니티 사용자 피드백용 통합본

## 현재 구성

Q&A·생활정보·공지의 3개 게시판 유지. 검색·글쓰기·저장한 글에 본인 글 수정, 댓글 초안, 내 활동을 추가했다.

| 영역 | 반영 내용 |
| --- | --- |
| 탐색 | 상단 제목·게시판·검색이 내용과 함께 자연스럽게 사라지는 페이지 스크롤. 구분선과 여백 보강. 검색 입력 내부 포커스 테두리 제거, 검색창 전체에 포커스 표시 |
| 화면 간소화 | 답변 없는 질문 필터·최신 글 표시·상시 소개문 제거 |
| 첫 방문 | 계정·기기별 9단계 맥락형 안내. Q&A→생활정보→공지→검색→글쓰기→게시판→샘플 입력→게시→목록 예시. 강조 영역은 투명하게 노출하고 10px 여백, 하단 고정 설명, 강조 대상을 가릴 때만 위치 보정. 건너뛰기·뒤로·Escape·? 재실행 지원 |
| 글 관리 | 본인 글 상세에서 수정. 기존 제목·본문·언어 불러오기, 저장 성공 뒤 상세 복귀. 신규 글 초안과 수정 입력 분리 |
| 댓글 초안 | 계정·게시글별 sessionStorage. 뒤로 가기·탭 이동·새로고침 복구. 전송 실패 시 유지, 성공 시 제거. 저장 실패 표시 |
| 내 활동 | 상단 말풍선 아이콘 → 내 글 / 내 답변. 서버의 본인 활동 조회, 삭제·숨김·차단 글 제외, 추가 불러오기 |
| 자동 번역 | 선택한 앱 언어로 목록 제목·미리보기·상세·댓글 자동 번역. 원문 유지 및 상세/댓글 원문 전환. 목록의 기기 미연결 안내는 제거. 개별 번역의 처리·실패 상태는 유지 |

신청서·일정·박해 진술은 커뮤니티에 자동 공개하지 않는다. 개인정보 주의는 글 작성 화면에서 강조한다. 작성 언어는 앱 언어를 사용하고 별도 선택기는 제거했다. 정상 임시 저장 문구는 생략하되 저장 실패 경고는 유지한다.

## 저장·권한 경계

게시글/댓글 초안은 현재 브라우저 탭에 저장하며 탭 종료 후 보존은 보장하지 않는다. 저장한 글은 계정별 localStorage에 ID만 최대 200개 저장한다. 본인 활동은 기존 Supabase에서 조회한다. 수정은 본인·공개 상태 조건과 기존 RLS를 함께 사용하며 새 DB migration은 필요하지 않다. Supervisor는 별도 로컬 가상 데이터만 변경한다.

## 번역 환경

Android ML Kit가 있으면 오프라인 번역을 사용한다(처음에는 언어 모델 다운로드 필요). 그 외에는 준비된 기기 모델·로컬 미리보기 모델을 사용한다. 느린 모델도 화면에 보이는 목록부터 자동 번역하며 동시 실행은 1개, 빠른 번역기는 2개로 제한한다. 번역 캐시와 중복 요청 결합을 적용한다. Hybrid 외부 모델로 자동 우회하지 않는다. Supervisor도 실제 번역기가 준비되면 같은 경로를 사용한다.

번역기 미연결 시 원문과 상태를 표시한다. 원문 검색이며 번역문 전체를 대상으로 한 서버 검색은 이번 범위가 아니다.

## 확인 결과와 남은 검증

319개 테스트·웹 빌드 통과. 새 안내는 6개 언어·390×844 및 한국어/아랍어 320×640에서 강조 영역/설명 겹침, 자연스러운 스크롤, 샘플의 실제 미게시·임시 글 보존·첫 글쓰기 안내를 확인했다. 6개 언어, 320/390px에서 첫 방문 안내, 본인 글 수정, 댓글 이동/새로고침 복구와 전송 후 정리, 내 글·답변, 상단 고정과 입력 포커스를 확인했다. 데이터는 Supervisor 가상 데이터다. 자동 번역·원문 전환은 명시적인 가짜 로컬 모델 응답으로 연결 동작을 확인했으며 번역 품질 시험은 아니다.

실계정 Supabase 2개 계정의 RLS, 실제 Android 번역 엔진/다운로드/속도, 동일 시각 게시물의 기존 timestamp 페이지 경계, 서버 전송 재시도의 멱등성은 별도 검증 대상이다. 이번에 운영 DB나 APK를 검증했다고 주장하지 않는다.

## 샘플 안내의 경계

튜토리얼은 실제 PostComposer를 재사용해 제목·본문 입력란에 예시를 채운다. demo 모드로 저장/게시를 차단하고 사용자 초안과 분리한다. 마지막 목록에서는 화면을 어둡게 하지 않고 샘플 카드만 강조한다. 게시 API, 실제 글 초안, 댓글에는 쓰지 않는다. 샘플은 완료·건너뛰기 시 제거한다. 동작 줄이기 설정에서는 타이핑 효과를 생략하고, 다음 단계는 자동으로 넘어가지 않는다. 처음 홈 안내를 건너뛰면 실제 글쓰기 첫 방문에 별도 안내를 제공한다.

## 11월 27일 작성 화면 보완

닫기(X)·중앙 제목·등록의 간결한 헤더, 제목 구분선과 본문 중심 입력란, 내용에 따른 높이 확장. 개인정보 안내는 하단 회색 박스·붉은 테두리에 세 항목으로 정리했다. 별도 익명 기능이나 게시 정책을 추가했다고 표시하지 않는다.

사진/파일 선택·로컬 미리보기·삭제 지원. JPG/PNG/WebP/PDF/TXT, 파일당 10MB·최대 3개. 미리보기 URL은 삭제·화면 종료 시 해제한다. 업로드/게시글 첨부 저장은 미구현이며 UI에 표시한다. 첨부가 선택돼 있으면 등록을 막아 파일이 누락된 채 게시되지 않도록 했다. 사용자 초안에는 파일을 저장하지 않는다.

6개 언어에서 안내 중 강제로 submit 해도 게시되지 않는지, 실제 폼 예시 입력·원래 초안 보존·마지막 마스크 투명, 사진/파일 선택·삭제·등록 차단을 확인했다. 320×640 한국어/아랍어에서 실제 타이핑 효과와 안내 겹침도 확인했다. 실제 파일 서버 업로드나 Android 파일 선택기를 검증한 것은 아니다.
