## 수정한 문제

| 우선순위 | 재현한 문제 | 반영 내용 |
| --- | --- | --- |
| P0 | 스케줄러를 보는 중 신청서 번역이 끝나면 신청서 가이드가 뜨고 스크롤이 맨 위로 이동 | 현재 활성 탭에서만 가이드·초기 인사·스크롤·포커스 효과 실행. 숨겨진 신청서의 답변·대화·모델 작업 상태는 유지 |
| P1 | 커뮤니티 게시글 수정 중 다른 탭으로 이동하면 수정 내용 유실 | 계정·게시글별 수정 버퍼를 sessionStorage에 분리 보관. 다시 수정할 때 복원하고, 저장 성공 시 해당 버퍼만 정리 |
| P1 | 저장 실패 시 미번역·미확인 답변으로는 실행할 수 없는 Word 다운로드를 안내 | 페이지 유지·새로고침 금지·원문 복사 안내로 교체. 6개 언어 적용 |
| P2 | 파일 생성·다운로드 실패를 번역 실패로 안내 | 실제 실패 단계에 맞는 다운로드 안내로 수정. 6개 언어 적용 |

앞선 로컬 수정인 신청서 첫 사용 가이드·`?` 다시 보기·뒤로가기 hover 잔상 제거도 유지.

수정 버퍼는 새 글 임시 저장과 분리. 다른 계정·게시글에서 읽지 않으며, 늦게 도착한 저장 응답이 더 최근의 수정 내용을 삭제하지 않도록 보호. 저장 데이터가 손상됐을 때 자동으로 덮어쓰거나 삭제하지 않음.

## 검증 결과

| 영역 | 실제 확인한 흐름 |
| --- | --- |
| 신청서 | 한국어 작성 → 번역 확인 → 명시적 확인 전 저장 차단 → 확인 → Word 다운로드 → 새로고침 후 답변 복원 |
| 탭 전환 | 번역 응답을 지연시킨 뒤 스케줄러로 이동. 응답 완료 후에도 스케줄러 유지·스크롤 300px 유지·신청서 모달 미표시 |
| 스케줄러 | 일정 2개 등록·수정·새로고침 복구, 준비 서류 체크 복구, 자료 구하는 방법 팝업·기관 목록·전체 절차 팝업 |
| 커뮤니티 | 새 글 임시 저장·탭 이동 후 복원·게시, 수정 임시 저장·수정 게시, 댓글 임시 저장·등록, 검색·북마크·내 활동·삭제 |
| 화면 | 한국어·영어·프랑스어·러시아어·아랍어·페르시아어. 주요 화면을 320·390·768·1280px에서 확인. 가로 넘침·실행 오류 없음 |
| 자동 검증 | 회귀 테스트 325개 통과, TypeScript 검사·프로덕션 빌드 통과 |

브라우저 검증은 로컬 Supervisor의 가상 데이터 사용. 외부 서비스에 실제 게시하거나 실제 신청자의 정보를 사용하지 않음. 탭 전환 테스트의 번역 응답은 모의 응답이며 실제 모델 품질·속도 평가가 아님.

## 배포 전 남은 확인

| 항목 | 현재 상태와 다음 확인 |
| --- | --- |
| 실제 번역 | 점검 시 `127.0.0.1:8765` 모델 API 연결 불가. 다른 언어의 실제 번역 품질·지연 시간은 모델 연결 후 확인 필요 |
| 운영 로그인·커뮤니티 | 실제 Supabase 계정의 이메일 인증·권한·RLS·다중 사용자 동작은 이번 로컬 검증에 포함하지 않음 |
| Android | APK·실기기·기기 번역 모델 미검증. 신청서 저장은 현재 웹 Blob 다운로드 경로이므로 Android에서 실제 파일 저장 여부 확인 및 필요 시 네이티브 저장 경로 구현 필요 |
| 게시글 첨부 | 현재 파일 선택·미리보기 시안. 업로드·첨부 게시 미구현이며, 첨부가 선택된 동안 게시를 막는 기존 동작 유지 |

현재 브랜치의 로컬 수정이며 push·PR·main 병합은 수행하지 않음.
